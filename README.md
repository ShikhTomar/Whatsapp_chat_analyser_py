# Whatsapp_chat_analyser
✨ Features Overall Statistics: Total messages, words, media shared, and links shared.

Monthly & Daily Timeline: Visualize how conversation frequency changes over time.

Activity Map: See the busiest days of the week and months.

Weekly Activity Heatmap: A detailed hourly and daily breakdown of chat intensity.

WordCloud: Beautiful visualization of the most frequently used words.

Most Busy Users: (For group chats) Analyze who contributes the most to the conversation.

Emoji Analysis: Breakdown of the most used emojis in the chat.

🛠️ Tech Stack Language: Python 3.13

Framework: Streamlit

Data Handling: Pandas

Visualization: Matplotlib, Seaborn, and Plotly

Processing: Emoji, Urlextract ⚙️ Installation & Setup Run the application locally:

Bash

streamlit run App.py 📖 How to Use 1 - Open WhatsApp on your phone.

2 - Go to the chat you want to analyze and click Export Chat (without media).

3 - Upload the exported .txt file into the application's sidebar.

4 - Select a specific user or choose "Overall" to see the analysis.
